# Feedback and contributions

YNX is a free community add-on maintained by Ynx.

For bug reports, include the YNX version, Azeroth Survivors client version (if known), exact steps to reproduce, and any Lua error line. Add a screenshot when it helps.

If proposing code changes, please open an Issue first so the direction can be discussed. **A source-code licence for contributions and redistribution has not yet been selected**; contact the author before submitting third-party code.
