# YNX v0.16.10 — Beta / Hotfix 1

**Released November 8, 2026** · [GitHub release](https://github.com/AlinFeraru/YNX/releases/tag/v0.16.10) · [Download YNX.zip](https://github.com/AlinFeraru/YNX/releases/download/v0.16.10/YNX.zip)

**Your build. Your stats. Your HUD.**

## Highlights

- **27 specialization themes** with spec-inspired backdrops and WoW class-colour borders.
- **Arcane, Modern, and Classic** reactive icon packs.
- **Seven interface languages:** English, Spanish, French, German, Simplified Chinese, Russian, and Korean.
- Redesigned menus, layout/frame customization, bar controls, text options, and live HUD previews.
- **All Stats** preset plus combinable stat sets without duplicates and customizable named profiles.
- Option to hide the percentage symbol while keeping numerical percentage values.
- Reduced unnecessary redraws and redundant UI texture updates.

## Hotfix 1

Fixed a Lua runtime error in the colour picker caused by a stale palette-label reference.

## Installation

1. Download **`YNX.zip`** from the release assets.
2. Extract the **`YNX`** folder into the game's addon directory (commonly **`benilla-config/AddOns/`**).
3. Verify **`YNX/YNX.toc`** exists directly inside your addons directory.
4. Restart the game.

Preserve **`ABASettingsDB`** SavedVariables to retain settings and profiles.

**Important:** This release's **`YNX.zip`** asset is the installable addon. The repository's `YNX/` source tree and GitHub's auto-generated source archives may reflect an earlier snapshot.
