YNX 0.10.1 - Free X/Y Positioning Hotfix

- Removed the hard UIParent-width/height clamping that created an invisible drag boundary on some client sizes.
- Unified HUD placement under a TOPLEFT anchor using signed X/Y offsets in UI units (X right, Y down).
- LOOK > LAYOUT: numeric X and Y fields (Enter to apply) plus -/+ nudge buttons (10 UI units per click).
- Positions persist in SavedVariables as hudXY. Existing v0.10 hudPlacement coordinates are migrated automatically.
- HUD top-left remains stable when changing scale/width/height; settings still stay centered.
- RESET POSITION and /ynx reset safely recover an HUD moved off-screen.
- No changes to stat selections, tracking, presets, themes or milestone bars.

Validated in a simulated Lua client: input, drag, UI scale, saved-position migration,
free movement outside virtual UI bounds, and existing UI control regressions.
Actual Azeroth Survivors client verification is still required.
