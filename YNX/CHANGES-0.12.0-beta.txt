YNX v0.12.0-beta — Animated compact HUD pass

Highlights
- Stable stat widths during change animations.
- Floating gain preview: current value stays fixed, gain text appears separately.
- Added icon pulse/halo feedback when a stat changes.
- New ROUNDLESS frame style: rounded panel without border.
- New HUD text controls: font family and number baseline.
- Default starter preset now uses a 2-column six-stat layout: Damage, Haste, Crit, Crit Damage, Luck, Echo.
- Proc icon lookup now prefers meter-provided icons / learned spell icons, with fallbacks for common proc names.
- Modern icon art applied more broadly across the addon UI.
