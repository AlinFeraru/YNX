YNX v0.11.0-beta — Visual overhaul

- 29 polished modern stat icons (keeps the original classic icon style selectable).
- Cleaner settings typography using client-provided Arial Narrow and a
  Morpheus-style title, with a safe fallback to the game's default font.
- Settings window can be dragged using its title bar. The position is saved
  independently from the HUD, and the R button recentres the Settings window.
- Refreshed Settings panel and button textures with clearer selected states.
- Three visual presets: ARCANE, MYTHIC and NEON, with distinct theme/frame/icon
  combinations; none alter which statistics are tracked.
- Smoothly interpolated milestone bars and brief highlights for increases.
- Subtle icon halos in supported frame modes.
- Existing profiles, HUD positions, classic skins and stat selection preserved.

BETA LIMITATIONS
- Built for the Azeroth Survivors WoW 1.12/Lua 5.0 client.
- Syntax and simulated interaction tests passed; exact rendering still needs
  verification in the actual game (font fallback, TGA alpha and screen dragging).
- Not yet published to GitHub or SurvivorsForge. Stable v0.10.1 is unchanged.

INSTALL
- Keep a backup of v0.10.1 and preserve SavedVariables.
- Replace the existing YNX folder with this beta's YNX folder and restart.
